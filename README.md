# Дед Мороз и Снегурочка на дом, Казань

Одностраничный сайт для записи на 20-минутный визит к семьям с детьми 3-10 лет. Даты: 28-31 декабря.

## Запуск

Сборки нет: статические файлы. Открыть локально:

```
python -m http.server 8765
```

и зайти на http://localhost:8765/

## Файлы

- `index.html`: сайт целиком (разметка, стили, скрипт).
- `variants.html`: три варианта календаря и формат отзывов. На сайте выбран вариант Б.
- `img/`: фото и иконки мессенджеров. `img/src.webp`: исходное фото.

## Что править в конце `index.html`

- `TG`, `WA`, `PHONE`, `MAX`: контакты. `MAX` пустой: нужна ссылка из приложения (Профиль, значок QR, "Скопировать ссылку").
- `BUSY`: занятые слоты в формате `'день-час'`, например `'30-18'`. Полночь 31-го: `'31-0'`.
- `REVIEWS`: 8 отзывов (`name`, `date`, `text`). Пока текст пустой, карточка помечена "Образец".
- `price()`: цены. 5000 ₽ обычный слот, 6500 ₽ 31 декабря с 18:00, 9000 ₽ в 23:00 и 00:00.

## Не сделано

- Настоящие отзывы. С образцами публиковать нельзя, выдуманные не ставить.
- Ссылка на профиль MAX. Сейчас кнопка копирует сообщение в буфер и ведёт на max.ru.
- Версия для телефона: вёрстка только под десктоп 16:9.
- Купоны и скидки: предложены, суммы не утверждены.
- Ролик, где герои машут рукой, для первого экрана.
- Домен и публикация.

## Правила текста

На странице нет слов "актёр", "аниматор", "парик", "грим": её может увидеть ребёнок.
